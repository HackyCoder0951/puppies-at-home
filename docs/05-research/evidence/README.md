# Research evidence (private, not in git)

This folder holds the raw material behind the research and visual analysis. **Its contents are ignored by git** (see the repository `.gitignore`) because they are large and include photos of real customers and content that belongs to the reference site's owner. Keep a local copy only; do not publish it (`docs/03-security-privacy/06-security-architecture.md`, sections 6.13 and 6.15).

| Subfolder | Contents | Notes |
|---|---|---|
| `captures/` | `reference-home.html`, `reference-site.css`, `sitemap.xml`, `robots.txt` | Copies of the reference site's public files, saved 2026-11-01 around 22:02 IST for analysis only |
| `pages/` | 27 desktop screenshots in 7 folders (`home` 10, `puppies` 5, `gone-home` 2, `happy-families` 3, `how-it-works` 4, `faq` 2, `visit-contact` 1) | Captured by the owner at mixed browser zoom levels (about 100%, 80% and 67%); see `docs/04-design-ux/reference-analysis/screenshot-inventory.md` |
| `video-recording/` | `puppies-at-home-reference-demo.mp4`, 7:12, 1920×1080, 60 fps, about 103 MB | Owner's screen recording of the reference site; exact timeline in `docs/04-design-ux/reference-analysis/interaction-analysis.md` |
| `pages-mobile/` (planned) | Mobile reference captures at 375×812 and other widths | Not supplied yet (decision D14) |

The analysis documents cite these files by path; they remain valid on any machine that has the local copy.
